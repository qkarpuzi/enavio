RAG AI Assistant · Higher Education

An AI assistant for a 20,000-student university

Public code — verify it yourself View on GitHub →
01 — The Challenge

Students and staff need answers general AI can't give

AAB College, the largest non-public university in Kosovo, has its own programs, policies, and institutional information that a general-purpose chatbot simply doesn't know — and will guess at anyway.

02 — The System

A retrieval-augmented assistant

An AI assistant that retrieves relevant passages from AAB's actual programs, policies, and institutional documents at answer time, then generates a response grounded in what it retrieved.

03 — How It Works

Retrieve first, answer second

A question comes in, relevant institutional documents are retrieved from AAB's records, and the assistant answers using only that retrieved content — rather than recalling from general training data.

04 — Technology

RAG, LLMs, and institutional data

Built on retrieval-augmented generation over AAB's own document set, using large language models for the conversational layer.

Retrieval-Augmented Generation Large Language Models Institutional Data

Built and working

The assistant is built and answering questions grounded in AAB's actual institutional information. Full code is public on GitHub.

OCR & Document Classification

A system that reads and sorts documents on its own

Public code — verify it yourself View on GitHub →
01 — The Challenge

Manual document sorting doesn't scale

Organizations receive a steady stream of scanned documents and photos of paperwork. Sorting and filing them by hand is slow and error-prone.

02 — The System

OCR plus automatic classification

A system that takes a scanned document — or just a photo of one — extracts the text with OCR, and automatically classifies what type of document it is.

03 — How It Works

Extract, then classify

Text is extracted from the image using optical character recognition, then the extracted content is run through a classifier that determines the document type — no manual sorting step required.

04 — Technology

Computer vision and classification models

Built on OCR and computer vision for text extraction, with a classification layer for document typing.

OCR Computer Vision Classification Models
05 — Status

Built and working

The system reads and classifies documents, including imperfect scans and photos rather than only clean, flatbed-scanned input. Full code is public on GitHub.

In progress · Construction & Risk Management

Risk visibility for construction projects

In development — public repo View on GitHub →
01 — The Challenge

Invoices and project data drift apart

On construction projects, invoices and project records can quietly stop matching — and projects that were expected to win can start losing ground — without anyone noticing until it's expensive.

02 — The System

A dashboard with a chatbot

Currently building: a dashboard, paired with a chatbot, that cross-references invoices against project data for construction companies.

03 — How It Works

Cross-reference and flag

Invoices are checked against project records. Mismatches are flagged, and projects trending away from expectations are surfaced — instead of being found the hard way, later.

04 — Technology

Data cross-referencing and conversational access

Structured data comparison across invoice and project records, with a chatbot layer for querying the dashboard directly.
